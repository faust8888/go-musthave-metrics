# cmd/server

В данной директории находится код сервера метрик.

Для ограничения адресов агентов задайте доверенную подсеть в CIDR-формате через `-t`, переменную окружения `TRUSTED_SUBNET` или поле `trusted_subnet` JSON-конфигурации, например `192.168.1.0/24`. Сервер принимает метрики только с адресов из этой подсети по заголовку `X-Real-IP`. Пустое значение отключает проверку.
